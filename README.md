# Introduction

*Is that a one-handed weapon or a two-handed weapon?*

This cosmetic mod flips the weapon artwork of many weapons so their direction aligns cosistently and uniformly with how they are rendered on the character model. This allows new player to easier identify which weapon is one-handed and which one is two-handed.

### Main Changes ###

- Flip melee weapon images so that: they align more with how they look on the battlefield
	- One-Handed melee weapons face top-right
	- Two-Handed melee weapons face top-left

### Compatibility

- This mod supports most Vanilla and Reforged melee weapons

### Known Issues

- Mods, which display those icons in other places than the inventory (e.g. **Extra Keybinds**), might use the non-flipped versions of the artwork

### Requirements ###

- Modding Script Hooks
- Modding Standards and Utilities (MSU) 1.5.0
- Modular Vanilla
